bash
gdb ./your_program
gef➤  pattern create 100
Output: aaaabaaacaaadaaaeaaaf...

Crash the program with the pattern:

bash
gef➤  run < <(python3 -c 'print("aaaabaaacaaad...")')
Check the value of $eip (or $rip for 64-bit) after the crash:

bash
gef➤  pattern offset $eip
This gives the exact offset to the return address.
