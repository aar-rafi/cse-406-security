The file_crypto.py module provides functionality for:
1. Encrypting files of any type and size
2. Decrypting encrypted files
3. Preserving file metadata
4. Verifying file integrity
5. Streaming large files in chunks for memory efficiency

This implementation can handle:
- Text files like this one
- Binary files like images and executables
- PDF and document files
- Any other file type

The file encryption adds the following security features:
- AES encryption in CBC mode
- Random IV for each file
- File integrity verification via SHA-256 hash
- Key stretching for user-provided passwords
- Metadata preservation with the encrypted file
